# BarcaLive - FC Barcelona Fan Hub

**BarcaLive** is your premium, real-time command center for everything FC Barcelona. Designed for fans who demand speed, aesthetics, and live visual updates without the clutter.

## Key Features

- **Live Match Center**: Real-time scores, match status, and dynamic updates.
- **Schedule & Fixtures**: Stay ahead with a complete calendar of La Liga and Champions League matches.
- **Immersive Design**: A "Glassmorphism" UI with dynamic backgrounds that react to the team's identity.
- **Fast & Responsive**: Optimized for speed with instant loading and mobile-first experience.
- **Global Access**: Available in English and Polish.

## For Users

Simply open the website to see the latest match status. The background and interface adapt to provide a premium visual experience whether you are on mobile or desktop. No login required—just pure Barça passion.

## Technical Info (For Developers/Deployment)

This project is built with:
- **HTML5 & Vanilla JavaScript**: For maximum performance and zero runtime overhead.
- **Tailwind CSS (v4)**: For rapid, modern styling (compiled ahead-of-time).
- **Supabase**: For real-time data data fetching.

### Deployment (Cloudflare Pages)
- **Build Command**: `npm run build`
- **Build Output Directory**: `.` (Root)
